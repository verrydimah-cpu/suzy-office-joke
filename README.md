One line of office comedy: "My boss said dress for the job you want, so I came as a retired person and HR called it a policy violation." The joke takes the familiar office advice literally — the job actually wanted is retirement — and holds its payoff to the last words, where HR treats the honest outfit as a policy violation. The program in `main.ts` (Node 22, standard library only) writes that single joke, byte-identically on every run, to `entry.txt` in the output directory (`/output`, or `$MAKEFUN_OUTPUT_DIR` anywhere else), clearing only the directory's contents first.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
